# Estagio-1-Curso-Java-MySQL-Hibernate-Tasks-For-Employees
 
Um projeto em Java + Servlet + Hibernate puro para gerência de tarefas e funcionários

Este projeto é uma aplicação **Java Web** desenvolvida com **Servlets + JSP** e **Hibernate puro**, focada na gerência de **funcionários** e **tarefas** em um ambiente corporativo simples. Ele faz parte do meu **treinamento corporativo**, com o objetivo de consolidar práticas reais utilizadas em sistemas empresariais Java tradicionais. O objetivo é servir como base de estudo e prática para aplicações Java EE tradicionais, sem o uso de frameworks como Spring.

---

## 📌 Funcionalidades

### 👤 Funcionários

* Cadastro de funcionários
* Listagem de funcionários
* Edição de dados
* Remoção de funcionários

### 📝 Tarefas

* Criação de tarefas
* Associação de tarefas a funcionários
* Atualização de status (pendente e concluída)
* Listagem de tarefas

---

## 🛠️ Tecnologias Utilizadas

* **Java 8+**
* **Servlets**
* **JSP**
* **Hibernate ORM (sem Spring)**
* **JPA (anotações)**
* **Apache Tomcat**
* **Banco de dados relacional** (MySQL / PostgreSQL)
* **Maven** (gerenciamento de dependências)

---

## 🧠 Conceitos Aplicados

* MVC (Model-View-Controller)
* DAO Pattern
* Hibernate Session e Transactions
* Relacionamento entre entidades (OneToMany / ManyToOne)
* Servlets para controle de fluxo
* JSP para camada de visualização

---

## 🎯 Objetivo Educacional

Este projeto tem como foco:

* Aprender **Hibernate na prática**, sem abstrações
* Entender o funcionamento real de **Servlets e JSP**
* Consolidar conceitos de **persistência de dados em Java**
